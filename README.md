# 삐약이의 생일 대모험

09월 14일을 위한 모바일 생일 퀘스트 웹앱입니다.

## 실행

별도 설치나 빌드 과정이 없습니다. `index.html`을 브라우저에서 열거나 아래처럼 간단한 정적 서버를 실행하세요.

```bash
python3 -m http.server 4173
```

그다음 `http://localhost:4173`에 접속합니다.

## 내용 수정

이름, 생일, 최종 선물명과 편지는 `app.js` 상단의 `PROTECTED_CONFIG`에 AES-GCM 암호문으로 저장됩니다. 공개 저장소에는 PIN과 원문이 포함되지 않습니다. 내용을 바꿀 때는 새 PIN으로 암호문을 다시 생성해야 합니다.

진행 상황은 브라우저의 `localStorage`에 자동 저장됩니다. 우측 상단 메뉴에서 처음부터 다시 시작할 수 있습니다.

## 홈 화면 앱으로 설치

HTTPS 주소로 한 번 접속하면 PWA로 설치할 수 있습니다. 아이폰은 Safari의 `공유 → 홈 화면에 추가 → 웹 앱으로 열기`, 안드로이드는 브라우저 메뉴의 `앱 설치`를 사용합니다. 첫 접속에서 화면과 캐릭터 리소스를 저장하므로 이후에는 네트워크가 불안정해도 실행할 수 있습니다.

## 배포

별도 서버 코드가 없는 정적 앱이므로 GitHub Pages에 그대로 배포할 수 있습니다. 저장소의 루트를 Pages 소스로 지정하면 HTTPS 주소가 생기며, 이후 파일을 갱신해 다시 올릴 수 있습니다. `.nojekyll` 파일을 포함해 정적 파일을 그대로 서비스하도록 구성했습니다.

Synology NAS에서는 Web Station의 문서 루트에 이 폴더를 복사해 서비스할 수 있습니다. PWA 설치와 휴대폰 공유 기능을 사용하려면 NAS의 DDNS 도메인과 유효한 HTTPS 인증서도 설정해야 합니다. 컴퓨터의 임시 HTTP 서버는 같은 네트워크에서 확인하는 개발 테스트용으로 사용합니다.

## 생일 여행 에디션 (v4)

- 수원 성곽 풍경과 초대장, 종이 쿠폰을 모티브로 화면을 통일했습니다.
- 미역국·디저트 질문에 선택별 답장이 오고, 산책 미션과 열기구 게임을 진행합니다.
- 초대장·카페·행궁동 장면에는 하트가 하나씩 숨어 있습니다. 선택 사항이며 놓쳐도 엔딩에 도달합니다.
- 열기구 운항이 어려우면 다음 데이트로 이월할 수 있습니다. 실제 운항 정보를 조회하거나 예약하는 기능은 아닙니다.
- 마지막에 선물을 먼저 고르면 울고 있는 뇽뇽이의 편지를 한 번 더 생각해볼 수 있고, 편지 또는 선물로 다시 선택할 수 있습니다. 엔딩에서는 생일 촛불을 끄고 한 줄 메시지를 저장하며, 오늘의 기억·편지·더풋샵 선물권을 각각 휴대폰용 PNG 이미지로 저장할 수 있습니다.
- 기존 v3 진행 데이터는 유지합니다. 저장이 손상되었을 때 초기 화면으로 복구합니다.

캐릭터는 `assets/characters/`의 **독립된 투명 PNG 8장**을 사용합니다. 삐약 3포즈(기본·신남·하트), 뇽뇽 5포즈(기본·신남·하트·긴장·선물)입니다. 이미지 전체를 `object-fit: contain`으로 표시하며, 스프라이트 시트나 가장자리 자르기를 사용하지 않습니다. 원본 시트와 이전 파일은 그대로 보존했습니다.

삐약은 기본 장면에서 살짝 들썩이고, 신나는 장면에서는 통통 뛰며, 하트 장면에서는 좌우로 흔들립니다. 뇽뇽도 포즈에 맞춰 움직입니다. 기기의 동작 줄이기 설정을 켜면 애니메이션이 멈춥니다. 이미지 생성 방식과 프롬프트는 `assets/characters/PROMPTS.md`에 기록했습니다.

## 검증

```bash
node tests/smoke.cjs
node tests/sprites.cjs
node tests/pwa.cjs
```

`tests/browser.cjs`는 디버깅 포트 9334로 실행한 Chrome과 `ws` 모듈을 사용합니다. 별도 테스트용 Chrome 프로필에서 실행하세요. 테스트 프로필의 게임 저장 데이터를 초기화합니다.

```bash
node tests/browser.cjs --ws-module /absolute/path/to/ws
PIYAK_TEST_PIN=<PIN> node tests/pwa-browser.cjs --ws-module /absolute/path/to/ws
```

320·390·480·1024px에서 기본 18개 장면과 선물 선택 경고 장면의 이미지 로드, 가로 넘침과 말풍선·캐릭터 겹침, 삐약의 포즈별 애니메이션, 동작 줄이기 설정, 전체 진행, 두 엔딩, 저장 복원을 확인합니다. `sprites.cjs`는 8장 모두 실제 투명도와 실루엣 주변 여백을 검사합니다. 장면 미리보기는 `index.html?qaStep=0`부터 `qaStep=17`까지이며, 선물 경고는 `index.html?qaStep=16&reward=gift`, 저장 기능이 있는 엔딩은 `index.html?qaStep=17&ending=1`로 바로 볼 수 있습니다. 미리보기 진행은 실제 저장에 반영되지 않습니다.
